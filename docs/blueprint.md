# **App Name**: FotoClear

## Core Features:

- AI Background Removal: Automatically remove the background from uploaded product images using AI.
- Automatic Resizing: Resize images to predefined dimensions optimized for Tokopedia, Shopee, and Instagram.
- Manual Crop Adjustment: Allow users to manually adjust the crop area for resized images.
- Ad Display: Display ads between image edits for monetization.
- Freemium Subscription: Offer a freemium subscription with high-resolution downloads, batch processing, and custom background options.
- AI Background Generation: Generate relevant custom backgrounds to replace the removed background, providing users with a variety of visually appealing options as a tool.

## Style Guidelines:

- Primary color: Vibrant blue (#29ABE2) to convey trust and clarity.
- Background color: Light gray (#F0F2F5) for a clean and modern look.
- Accent color: Soft green (#90EE90) for positive actions and highlights.
- Body and headline font: 'PT Sans', a humanist sans-serif
- Code font: 'Source Code Pro' for displaying code snippets (if needed).
- Use clean and minimalist icons to represent various editing options and social media platforms.
- Use subtle transitions and animations when removing backgrounds and resizing images to provide a smooth user experience.
